# SOVIA Personality Type System

SOVIA is a fictional personality and labor-assignment system for the Comrade Sovia project. It is framed as an informal "Soviet-Oriented Vocational Identity Allocation" test developed by the Temporary Personality Review Section of the Propaganda Department.

The system does not claim to be psychological counseling, career advice, or a real organizational decision. It is a characterful classification framework for playful results, shareable profiles, music recommendations, and Sovia-themed content.

## Core Concept

SOVIA assigns each participant a five-letter labor personality code. Each letter represents one side of a binary axis:

1. Structure style
2. Action style
3. Influence style
4. Understanding style
5. Relation style

Because there are five binary axes, the system contains 32 personality types.

## Code Anatomy

Example:

```text
SOVIA
```

This means:

```text
S - Structure
O - Overdrive
V - Voice
I - Inquiry
A - Alliance
```

In plain English, SOVIA means:

> Structured, urgent under pressure, expressive, analytical, and collective-minded.

## Axes

### 1. Structure Style

| Letter | Name      | Meaning                                                                                        |
| ------ | --------- | ---------------------------------------------------------------------------------------------- |
| S      | Structure | Prefers order, plans, rules, procedures, and clear workflows.                                  |
| F      | Flow      | Relies on real-time judgment, adapts quickly, and dislikes being locked into rigid procedures. |

### 2. Action Style

| Letter | Name      | Meaning                                                                                            |
| ------ | --------- | -------------------------------------------------------------------------------------------------- |
| O      | Overdrive | Performs strongly under pressure and suits urgent tasks, crisis response, and sudden mobilization. |
| E      | Endurance | Works through steady, long-term, sustainable output instead of burning out in dramatic bursts.     |

### 3. Influence Style

| Letter | Name  | Meaning                                                                                |
| ------ | ----- | -------------------------------------------------------------------------------------- |
| V      | Voice | Good at expression, storytelling, framing, slogans, and shaping atmosphere.            |
| Q      | Quiet | Does not need to explain everything and prefers proving value through the work itself. |

### 4. Understanding Style

| Letter | Name    | Meaning                                                          |
| ------ | ------- | ---------------------------------------------------------------- |
| I      | Inquiry | Analyzes systems, causes, logic, structures, and mechanisms.     |
| M      | Meaning | Reads emotions, symbols, atmosphere, relationships, and stories. |

### 5. Relation Style

| Letter | Name     | Meaning                                                                               |
| ------ | -------- | ------------------------------------------------------------------------------------- |
| A      | Alliance | Values cooperation, collective rhythm, care for others, and shared completion.        |
| L      | Lone     | Keeps clear boundaries, works well independently, and dislikes frequent interruption. |

## Result Format

Each SOVIA result can contain:

- Type code
- Type title
- Assigned unit
- Short description
- Archive comment
- Sovia comment
- Personality profile
- Work profile
- Social profile

The preferred result-page framing is:

```text
Labor People's Allocation Certificate
```

**Short description:** Planned, urgent, expressive, systematic, and still willing to return to the collective.

**Assigned unit:** Propaganda Department Ideal Labor Personality Display Case

**Archive comment:** You received the SOVIA type. This does not mean you are Sovia, and it does not mean Sovia is SOVIA. It only means you are close to the ideal labor personality imagined by the Propaganda Department.

**Sovia comment:** Comrade, please do not mistake a propaganda poster for a selfie.

**Personality:** You are the kind of comrade the Propaganda Department theoretically likes most: planned, capable in emergencies, expressive, analytical, and collective-minded. The problem is that people like this usually exist in posters, manuals, and official speeches. You are not perfect. You just look very suitable for being printed as a model worker.

**Work style:** You make plans, prepare emergency options, and can present the final result like a victory. You suit complex tasks, cross-team coordination, and anything that nobody understands yet but everyone must understand. The risk is that you may take on too many responsibilities and become the default universal screw of the organization.

**Social style:** You can care for the collective while speaking with direction and confidence. Others may see you as reliable, inspiring, and able to hold a room. Some may also worry that you sound too much like an official document, even in casual conversation.

## Tone Guidelines

The SOVIA personality system should feel:

- Bureaucratic, but affectionate
- Soviet-inspired, but playful
- Serious on the surface, absurd underneath
- Warm rather than cruel
- Useful for identity play, not real psychological diagnosis

The best tone is not "you are a type." It is:

> The archive has assigned you a post, comrade. It may be a joke, but it recognizes something real.
